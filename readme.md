## ⭐ Projeto em destaque

### 🤖 Society Bots

O **Society Bots** é uma plataforma Android para criação, gerenciamento e operação de bots hospedados na Cloud.

Entre os recursos do projeto estão:

- gerenciamento de bots;
- integração com WhatsApp;
- QR Code e código de pareamento;
- logs em tempo real;
- Firebase Authentication;
- persistência no Firestore;
- integração com IA;
- importação de projetos;
- atualizações próprias do APK;
- gerenciamento remoto pela Cloud.
